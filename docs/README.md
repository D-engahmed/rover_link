## Documentation status vocabulary

**Implemented** means the current main branch contains the implementation.

**Partial** means code or a contract exists, but the end-to-end capability is incomplete.

**Experimental** means the capability is a research/development experiment and should not be presented as production behavior.

**Planned** means it is a proposed future change without current implementation evidence.

Documentation should preserve these distinctions.
